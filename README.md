# Biosignal Labeling Tool

Desktop-приложение для ручной разметки качества биосигналов.

Программа позволяет загружать сигналы из различных форматов, просматривать их
на графике и относить каждый фрагмент к одному из четырёх фиксированных классов
качества.

Проект разрабатывается для формирования собственного размеченного набора данных,
который в дальнейшем может использоваться для обучения моделей классификации
качества ЭКГ.

## Классы качества

Используются четыре фиксированных класса:

- **0 — Чистый** — выраженные шумы отсутствуют.
- **1 — Небольшой шум** — помехи присутствуют, но сигнал хорошо читается.
- **2 — Сильный шум** — сигнал значительно искажён, однако полезная информация
  ещё различима.
- **3 — Нечитаемый** — уровень помех не позволяет надёжно интерпретировать
  сигнал.

## Возможности

- просмотр биосигнала на графике;
- ручная классификация сигнала по четырём уровням качества;
- разбиение длинных записей на окна заданной длительности;
- настройка шага между окнами;
- выбор канала многоканального сигнала;
- автоматическое определение параметров для поддерживаемых форматов;
- сохранение результатов после каждой выполненной разметки;
- возможность остановить работу и продолжить её позже;
- переход к ранее размеченной записи по ID;
- изменение ранее назначенного класса;
- удаление разметки без изменения исходного датасета;
- просмотр списка уже размеченных записей;
- сохранение размеченных сигналов в едином формате `.npy`;
- формирование `labels.csv`;
- хранение состояния проекта в SQLite.

## Установка

Рекомендуется использовать виртуальное окружение Python.

```
git clone git@github.com:ElizavetaFrolova/biosignal-labeling-tool.git
cd biosignal-labeling-tool

python3 -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```
python src/main.py
```
